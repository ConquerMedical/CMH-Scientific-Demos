Rationale for individual-referenced models

Evidence from the type 1 diabetes study.

In 12 people with type 1 diabetes (194,010 five-minute observations), a model trained on the pooled population and models built from each person's own history were given the same task: find an intervention that moves high blood glucose toward a target.

POPULATION MODEL VS EACH PERSON'S OWN MODEL
24.5%

of tests gave the identical intervention

The population-trained model and the person's own model chose the same intervention in only 24.5% of evaluations. In the other 75.5%, they disagreed about what would move that person toward target. This measures agreement, not which answer was right.

ABP INVERSION · SEPARATE RESULT
96.0%

of 400 high-glucose cases moved toward target under ABP inversion

Queried in reverse under clinical constraints, ABP found an intervention direction that reduced the target gap in 96.0% of 400 high-glucose evaluations, with an average gap reduction of 87.8%.

A model trained on the population is not the same thing as a model built from the person. Faced with the same task, the two usually reached different conclusions about what intervention fits the individual. The comparison is architectural: it does not claim that every digital twin is built the same way.
Data provenance. Imaging: LUMIERE dataset (Suter et al., Scientific Data 9:768, 2022), de-identified longitudinal imaging and clinical annotations. Observed scans, recorded resections and postoperative courses are identified directly. LUMIERE does not record chemoradiation schedules; chemoradiation response calculations use the stated literature-informed functions.
