# CMH Scientific Interactive Demos — Final public set

This package contains the public interactive demonstration layer for CMH Scientific. It contains no protected engine implementation or secret API credentials.

Primary demos: Deferra Surgery, Deferra Anaesthesiology, OptiCeil, NPIS, TotemicAI, Acquire, TopolAI, ABP, AIO, CTF.

Architecture/support demos: CMH Interface, CMH Authenticated Gateway, CMH Guard.

The root `index.html` is the demo hub.
